Open-source multi-agent code review tool for GitHub PRs.

- Multiple AI agents review PRs or local changes, and findings open in an interactive UI.
- Each finding can be discussed, turned into a short comment, and published straight to the PR.
- Works as a Claude Code plugin (`/sieve:review`, `/sieve:inbox` for the review queue).

Vocabulary trainer for language learners, built solo as a full-stack developer. Responsive across all devices and screen sizes.

- **AI and learning:** Vercel AI SDK (OpenAI / Google) and Google Cloud Text-to-Speech, with spaced repetition via the FSRS algorithm for daily review queues.
- **AI integration:** MCP server that lets Claude build dictionaries and word cards directly in the app.
- **DevOps:** Docker-based deploy and GitHub CI, Sentry error tracking, automated releases with release-please.
